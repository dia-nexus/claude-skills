# claude-skills

dia-nexus が作った Claude のスキルを置いています。

| スキル | 中身 |
|---|---|
| cross-boundary-foundations | 事業、UX、システムのあいだで誰も決めていない決めごと（KPI、用語、状態、権限、コード値、エラーとログ、受け入れ条件、判断の記録、ダッシュボード）を仮決めし、表にして渡す。FDE、UXエンジニア、PdM 向け |

## cross-boundary-foundations について

解説ページ：https://claude.ai/artifact/GywViMYMUVRr9JMisE474G

このスキルは、FDE、UXエンジニア、PdMがビジネスとUXとエンジニアリングの間に立ち、三つを両立させるためのスキルです。

システムには、ログ、状態、権限、コード値といった決めごとがあります。これらはエンジニアが実装しながらよしなに決めていることが多いのですが、本当はビジネスやUXと深く絡んでいます。

たとえば、経費精算のシステムを作るとします。申請に領収書の添付漏れや金額の誤りがあると、経理の担当者はそれを申請者に戻して直してもらいます。これを「差し戻し」と呼びます。

顧客は「差し戻しを減らしたい」と言います。デザイナーは、経理が差し戻すときに理由を書ける入力欄を画面に置きます。エンジニアは、DB に「差し戻し済み」という印だけを残します。

半年後、顧客から「差し戻しの原因で一番多いのは何か」と聞かれます。調べようとすると、理由の欄は経理の担当者が自由に書いたままです。同じ「領収書がない」でも、ある人は「領収書なし」、別の人は「レシート添付忘れ」と書いています。100件並べると100通りの文になっていて、どの原因が多いのか数えられません。差し戻すときに「領収書なし」「金額の誤り」のようなタグを選んでもらっていれば、集計は一発で済んだはずです。

だから本当は、作る前に三者で次のことを一緒に決めておく必要がありました。顧客が知りたいのは原因ごとの件数なので、理由はタグで選ぶ形にする。そのタグを決まった値でDBに残す。タグごとの件数を毎月見る。

ほかにも、こういうことが起きます。

- 画面で編集ボタンを隠しても、APIからは審査中の申請を書き換えられてしまう
- 経費区分に「交際費」を足したら、去年の集計と比べられなくなる
- 送信がタイムアウトして「失敗しました」と出したが、実は登録済みで、申請者が送り直して二重申請になる
- AIが判定に迷った申請の行き先が決まっておらず、承認ボタンまでAIが押している
- 「審査が速くなった」と報告したいが、いつの時刻を記録すればよいかが決まっていない
- 前任者の作った画面がなぜこうなっているのか、誰も説明できない

決めないまま作っても、システムは動きます。困るのは本番に出てからで、過去のデータは戻らず、直すには移行の手間がかかります。

つまり、FDE、UXエンジニア、PdMは、ビジネスとUXの視点を持ってシステムを設計しなければいけません。それがこの役割の仕事です。そうして初めて、システムと事業の価値が両立します。

このスキルは、こうした決めごとを、ビジネス、UX、エンジニアリングの三つの目的を並べて検討するためのものです。扱うのは、KPIの式と計測、用語、状態、権限、選択肢とコード値、エラーとログ、受け入れ条件（AIなら評価の問題集）、判断の記録、ダッシュボードの定義と見る人の9つです。

このスキルを使うと、ビジネス、UX、エンジニアリングの目的を同じ表に並べて、整合性を取りながら検討できます。KPIで数えたいものは画面で選べる形になっているか。画面のラベルとDBの値は対応しているか。画面で隠した操作は、APIでも止まっているか。三つの目的がそろった表があれば、デザイナーもエンジニアも同じものを見て作れます。そうして作ったシステムは、そのまま事業の数字につながります。

## 入れ方

### Claude Code

Claude Code の中で、次の2行を順に打ちます。

```
/plugin marketplace add dia-nexus/claude-skills
/plugin install cross-boundary-foundations@dia-nexus-skills
```

2行目を打つと確認の画面が開くので、そこでインストールを選びます。

新しい版が出たら、`/plugin marketplace update dia-nexus-skills` で取り込めます。

### Claude のアプリ（claude.ai、デスクトップ）

1. このページの `dist/` から `cross-boundary-foundations.zip` をダウンロードする（ファイルを開いて、右上のダウンロードのボタン）
2. Claude のアプリで「カスタマイズ」→「スキル」を開く
3. 「＋」から「スキルを作成」→「スキルをアップロード」を選び、zip を選ぶ
4. 一覧に出たスキルをオンにする

メニューの名前は変わることがあります。見当たらなければ、設定の中のスキルの欄を探してください。アプリに入れたスキルは自動では新しくならないので、新しい版が出たら zip を入れ直してください。

## 中身の場所

- `plugins/<スキル名>/skills/<スキル名>/`：スキル本体（SKILL.md と、参照ファイル、テンプレート、点検用のスクリプト）
- `dist/<スキル名>.zip`：アプリに上げる用に、本体をそのまま zip にしたもの

スキルの使い方と変更履歴は、本体の README.md にあります。
